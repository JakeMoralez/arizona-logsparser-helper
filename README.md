**Arizona LogsParser Helper** — это браузерное расширение для Chromium-совместимых браузеров, разработанное для упрощения и автоматизации работы с логами серверов Arizona RP на домене `arizona-rp.logsparser.info`.

Расширение помогает структурировать отображаемую информацию, предоставляет инструменты для глубокого анализа сессий игроков, детекции подозрительной активности и ускоряет рутинные проверки для технической администрации.

## ⚡ Основные возможности

### 🎨 Кастомизация интерфейса и визуальные улучшения
* **Индивидуальная стилизация:** Выбор тем оформления (тёмная/светлая), цветовых схем (Arizona Red, Ocean Breeze, Emerald, Dracula и др.) и радиуса закругления элементов.
* **Своя цветовая тема:** Отдельные палитры для светлого и тёмного режима, настройка акцентных цветов, фона, карточек, таблиц, текста и границ с мгновенным предпросмотром.
* **Оптимизация пространства:** Возможность закрепить навигационную панель (`navbar`) и шапку таблицы, скрыть боковое меню, убрать верхние отступы или заменить стандартный Favicon.
* **Управление столбцами:** Кнопки быстрого скрытия/показа колонок данных и IP-адресов прямо из заголовка таблицы.
* **Плавающий фильтр:** Быстрый вызов модального окна фильтрации при прокрутке страницы.

### 🕵️‍♂️ Анализ данных и инструменты пробива (Интегрированная панель)
* **Расчет игрового онлайна:** 
  * Анализ времени сессий за выбранный период для одного или нескольких игроков.
  * Настройка «чистого» онлайна (учет определенного промежутка времени суток для будней и выходных).
  * **Скрытный режим:** сбор статистики онлайна на основе общих логов выхода без прямой фильтрации по никнейму.
* **Пробив наказаний и репортов:** Быстрый сбор выданных наказаний и детальной статистики ответов на репорты для группы администраторов с функцией поиска по содержимому.
* **Пакетный пробив IP и ID:** 
  * Получение последнего и регистрационного IP-адресов по логам выхода.
  * Сопоставление числовых ID аккаунтов с их Nick_Name.
* **Интеграция с GeoIP:** Автоматическое определение страны, города, провайдера и типа сети (мобильный, хостинг, прокси/VPN). Расчет приблизительного расстояния между точками авторизации с цветовой индикацией критических значений.

### 🤖 Аналитика и детекция нарушений
* **Проверка Email на ботов:** Определение дубликатов почтовых ящиков с настраиваемым порогом повторений и многоуровневой цветовой индикацией риска.
* **Детекция TG/VK ботов:** Выявление подозрительных регистраций и привязок нескольких аккаунтов к одному профилю Telegram или VK.
* **Контроль деталей тюнинга:** Автоматическое сканирование логов на установку тюнинга, подсветка строк по заданным временным паттернам (минуты/секунды), поддержка звуковых оповещений при совпадении.
* **Детекция идентичных IP:** Выделение строк с одинаковыми IP-адресами в рамках таблицы авторизаций.

### 📋 Автоматизация действий и копирование
* **Генератор команд (Менеджер форм):** Шаблонизация наказаний (например, `/banoff 0 {nick} 2000 Чит`) с автоподстановкой ников из таблицы и возможностью пакетного копирования готового списка.
* **Умное копирование:** 
  * Кнопки копирования всей строки лога в один клик.
  * Копирование отдельных ячеек без служебных символов и GeoIP-приписок.
  * Экспорт всех логов текущей страницы в буфер обмена.
* **Маскировка данных:** Функция скрытия конфиденциальной информации (частичное скрытие символов IP, Email, Telegram, VK) на экране и при копировании текста в буфер обмена.
* **Шаблоны поисковых запросов:** Сохранение часто используемых фильтров логов для быстрого применения в будущем.

## 📦 Установка расширения

### Из Chrome Web Store (Рекомендуется)
Вы можете установить расширение из официального интернет-магазина Chrome:
*   [Ссылка на Arizona LogsParser Helper в Chrome Web Store](https://chromewebstore.google.com/detail/imobodagdnhdmjjlpfajidiofikmmpgi)

### Ручная установка из исходного кода
Если вы хотите собрать или протестировать расширение самостоятельно:

1.  Клонируйте репозиторий или скачайте архив с кодом:
    ```bash
    git clone https://github.com/Arizona-AI/arizona-logsparser-helper.git
    ```
2.  Откройте браузер Google Chrome (или любой другой на базе Chromium) и перейдите на страницу расширений: `chrome://extensions/`.
3.  Включите **Режим разработчика** (Developer mode) в правом верхнем углу.
4.  Нажмите кнопку **Загрузить распакованное расширение** (Load unpacked) в левом верхнем углу.
5.  Выберите папку, содержащую файлы проекта (в которой находится `manifest.json`).

## ⚙️ Первичная настройка

1. Перейдите на страницу логов `https://arizonarp.logsparser.info/`.
2. Нажмите на иконку расширения на панели инструментов браузера для открытия всплывающего окна (Popup).
3. Во вкладке **«Внешний вид»** настройте отображение интерфейса по вашему вкусу.
4. Во вкладке **«Твики»** включите необходимые детекторы, настройте паттерны сканирования тюнинга, параметры маскировки и пороги для проверки почтовых ящиков.
5. Для ручной проверки IP воспользуйтесь полем ввода в нижней части вкладки «Твики».

## 🔒 Безопасность и конфиденциальность

* Расширение сохраняет настройки пользователя локально на вашем устройстве с использованием `chrome.storage.local`.
* Запросы к сервисам GeoIP проходят через внутреннюю очередь с задержкой, минимизируя передачу лишних данных.
* Функция маскировки позволяет безопасно делать скриншоты страниц логов для жалоб, не компрометируя личные данные игроков (IP, почты, привязанные соцсети).
